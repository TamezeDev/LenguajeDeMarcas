# Lenguajes de Marcas - Ejercicios de 1º de DAM

Colección de ejercicios prácticos e independientes realizados durante el módulo de **Lenguajes de Marcas y Sistemas de Gestión de Información** en 1º de DAM. Cada carpeta corresponde a una maquetación temática distinta, centrada en practicar estructura HTML, listas, tablas y estilos CSS con contenido variado (algunos con un enfoque desenfadado/humorístico como recurso didáctico).

---

## Ejercicios Incluidos

### 1. Recaudación de fondos (parodia)

### 2. Club Liberty (bar de copas)

### 3. Pedido de pepinillos

### 4. Donuts más buscados
---

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica, tablas, listas ordenadas/desordenadas.
- **CSS3:** Estilos básicos de maquetación y presentación visual.

---

## Cómo visualizar los ejercicios

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TamezeDev/lenguaje-de-marcas.git
   ```
2. Abre cada archivo `.html` de forma independiente en tu navegador (cada carpeta/ejercicio funciona por separado).
